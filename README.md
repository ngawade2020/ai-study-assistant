# AI Study Assistant

A modern AI-powered study assistant web application built using Python, Flask, HTML, and CSS.

The application allows users to:

* Ask AI-style study questions
* Upload PDFs for summarization
* Interact with a modern chat-based interface

---

# Features

* Modern AI-style chat UI
* Responsive design
* PDF upload support
* AI-style PDF summarization
* Real-time chat interface
* Smooth animations and transitions
* Clean sidebar layout
* Flask backend

# Installation

## 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

---

## 2. Open Project Folder

```bash
cd ai-study-assistant
```

---

## 3. Create Virtual Environment

```bash
python -m venv venv
```

---

## 4. Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

---

## 5. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 6. Run Application

```bash
python app.py
```

---

## 7. Open In Browser

```bash
http://127.0.0.1:5000
```
